# Stakeholder analysis

| Stakeholder | Interest | What the system gives them |
| --- | --- | --- |
| Student buyer | A trustworthy campus seller and a clear order state | Verified badge, ratings, purchase requests, chat |
| Student seller | A way to move unwanted items | Listings, auctions, exchanges, sales dashboard |
| Service provider | Paid-in-prototype tutoring and creative work | Service listings and request tracking |
| Administrator | A campus that stays safe to use | Suspension, content removal, reports, disputes, stats |
| College | Students are not using the platform to cheat | College email gate and a content rule against graded-work offers |
| Developer | A codebase that can be tested and changed | Separate models, services, and Jest coverage of the risky rules |

No individual student names are assigned as project owners. Responsibilities in `18-team-responsibilities.md` are by role.
