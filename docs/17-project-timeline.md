# Project timeline

The build is organized as eight phases. Dates below are the planned academic schedule ending 7 November 2026.

| Phase | Window | Outcome |
| --- | --- | --- |
| 1. Setup and authentication | 14 Sep – 27 Sep | Repo, MongoDB, register, verify, login, roles |
| 2. Marketplace | 28 Sep – 11 Oct | Listings, search, filters, uploads, wishlist |
| 3. Orders | 12 Oct – 18 Oct | Purchase locking, dashboards, simulated payment |
| 4. Auctions | 19 Oct – 28 Oct | Bids, anti-sniping, server close, watchlist |
| 5. Services | 29 Oct – 1 Nov | Catalogue, requests, academic-integrity check |
| 6. Exchange, chat, notifications | 2 Nov – 4 Nov | Proposals, Socket.IO messages, notification feed |
| 7. Trust and admin | 5 Nov | Reviews, reports, disputes, admin stats |
| 8. Tests and polish | 6 Nov – 7 Nov | Jest suite, seed data, docs, responsive UI |

Each phase is implemented in this repository rather than left as a paper plan.
